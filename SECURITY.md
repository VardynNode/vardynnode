# Security

To report a security issue in VardynNode, please use the page below. Please do not open a public issue for a vulnerability, and do not disclose it publicly before we have had a reasonable chance to fix it.

- Report form: https://vardynnode.com/security-report
- Policy (what to include, scope, how we respond): https://vardynnode.com/security
- Machine-readable contact: https://vardynnode.com/security.txt

You can also write to [hello@vardynnode.com](mailto:hello@vardynnode.com).

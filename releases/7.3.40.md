## What's new

- **Auto-update finishes reliably.** If an update is cut short (for example the server restarts while it runs), the dashboard no longer keeps showing an out-of-date update status. The bot notes that the update was interrupted, keeps running, and the next daily check completes the update by itself. Nothing needs to be done.
- **The bot starts once after an update**, not twice.
- **The holdings list counts small leftover amounts once.**
- **AI trade insight reads the whole answer.** It says plainly when an answer was cut off, and gives one warning per failure instead of three.
